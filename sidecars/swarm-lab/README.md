# Swarm Lab source

Standalone editable sources corresponding to the production Vite bundle mounted at `/sidecars/swarm-lab/index.html`.

From this directory run `bun install`, `bun run dev`, and `bun run test`. Run `bun run build` to typecheck, build with Vite, and automatically refresh the TokenHawk mount at `../../public/sidecars/swarm-lab/`. Do not edit the mounted bundle directly; edit `src/` and rebuild.
